# 杨浦区「三高一重」社区运动干预可视化数据大屏 — 展示原型

面向开发落地的高保真交互效果图（1920×1080 大屏适配），覆盖区级总览主屏与社区级子屏切换。

## 快速启动

```bash
cd dashboard
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可预览。

## 原型能力对照需求

| 需求 | 原型体现 |
|------|----------|
| 一屏展示核心结果性指标 | 区级顶部 KPI：签约总人数、标签人数、占签约比、戒烟调查完成率、建议书推送覆盖率、随访管理率 |
| 延展切换子屏 | 区级点击机构排名下钻 → 社区子屏；「返回区级总览」切回 |
| 区级横向对比与排名 | 机构综合绩效排名 + 四类指标横向对比柱图（已去掉数据来源模块） |
| 社区级医生明细 | 去掉团队字段；增加高血压 / 糖尿病 / 高血脂 / 超重肥胖随访统计 |
| 服务对象构成 | 年龄 / 性别 / 标签同屏完整展示，无切换、无滚动 |
| 分级权限 | 顶栏「区级视图 / 社区级视图」切换；社区级仅本机构数据 |
| 维度下钻 | 时间 / 年龄 / 性别筛选；趋势与画像分析 |

## 目录结构

```
dashboard/
  index.html
  src/
    App.jsx                 # 壳层：权限切换、筛选、主/子屏路由
    components/
      DistrictScreen.jsx    # 区级主屏
      CommunityScreen.jsx   # 社区子屏
      Chart.jsx / KpiCard.jsx
    data/mockData.js        # 演示数据（可替换为真实接口）
    styles/dashboard.css
```

## 设计说明（供开发还原）

- 画布：固定 **1920×1080**，按窗口等比缩放
- 视觉：深蓝科技大屏（网格底、装饰顶栏、面板角标）+ 青蓝主色
- 字体：Noto Sans SC（中文）+ JetBrains Mono（数值）
- 图表：ECharts（柱/折线/饼/玫瑰图）
